## Do you need a commercial license?

You need one if you want to do any of the following **without** meeting the AGPL's
requirements (source disclosure + AGPL copyleft, including the network/SaaS clause):

- Incorporate this code into a **proprietary / closed-source** product.
- Offer a **hosted or SaaS** product based on this code without publishing your complete
  source.
- Distribute this code under terms **incompatible with the AGPL**.
- Remove the obligation to release your modifications.

You **do not** need one if you're:

- Using it personally, internally, or for evaluation.
- Building something you're happy to release under the AGPL (with source).
- Learning from, forking, or contributing to the project.

If you're unsure, email **licensing@wishfulcoders.com** and we'll help you figure it out.

## What a commercial license grants

- A **non-exclusive, non-transferable** right to use, modify, and distribute the code in
  your own products **without** AGPL copyleft obligations.
- **No obligation** to publish your source or your modifications.
- The right to run it as a **hosted/SaaS** product privately.
- Optional: priority support and update access (see tiers).

It does **not** grant rights to the **Wishful Coders name, app names, or logos** — those
are trademarks and are handled separately.

## FAQ

**Can I evaluate it before buying?**
Yes. Evaluation and internal testing are fine under the AGPL — you only need the
commercial license when you ship/host without complying with the AGPL.

**Is the commercial-licensed code different from the open-source code?**
No — it's the same code. You're paying for *different license terms*, not different
software.

**I contributed code — can I still be required to buy a license to use the product commercially?**
The commercial license concerns the codebase as a whole. Contributors sign the
[CLA](./CLA.md) so we can offer both licenses; that's separate from any commercial use of
the assembled product. Ask us if your situation is unusual.
