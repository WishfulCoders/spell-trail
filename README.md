# Spell Trail

A calm, local-first spelling game designed around short practice sessions. Most questions use listening, recognition, missing-letter, or chunk-building activities; two of each eight questions use typing.

## Run it

```bash
npm install
npm run dev
```

Progress is stored only in the browser with `localStorage`. No account or backend is required.

## Checks

```bash
npm test
npm run build
```

## Deploy

The production build is served by Cloudflare Workers Static Assets.

```bash
npm run deploy
```
